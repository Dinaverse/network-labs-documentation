# Challenge: Discover - Secured data 1

## Overview
- **Category:** Steganography
- **Points:** 20
- **Difficulty:** Easy
- **Status:** Validated

## Description
What a great photo!

## Solution
The challenge involves finding hidden information within an image.
1. Visually inspect the provided image.
2. In the bottom right-hand corner, observe a string of text.
3. The text is written in a color very similar to that of the barriers in the image, making it difficult to see at first glance.
4. This string corresponds to the flag.

## Conclusion
Learned about simple visual steganography techniques where information is hidden by blending it into the background using similar colors.
