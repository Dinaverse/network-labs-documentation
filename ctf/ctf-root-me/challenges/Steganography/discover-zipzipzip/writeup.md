# Challenge: Discover - Zipzipzip

## Overview
- **Category:** Steganography
- **Points:** 20
- **Difficulty:** Easy
- **Status:** Validated

## Description
Zipping all kind of things.

## Solution
This challenge highlights the importance of exploring all files within an archive, including those that might be hidden by the operating system.
1. Download and extract the provided ZIP file.
2. Initially, only a single image file (a cute cat photo) is visible in the extracted folder.
3. Enable the display of hidden files in the operating system's file manager (e.g., in Windows File Explorer, go to the "View" tab and check "Hidden items").
4. A previously hidden text file will now be visible in the folder.
5. Open the hidden text file to reveal the flag.

## Conclusion
Learned that sensitive information can be hidden within archives using standard filesystem attributes (like the "hidden" attribute), and that thorough inspection of extracted contents is essential.
