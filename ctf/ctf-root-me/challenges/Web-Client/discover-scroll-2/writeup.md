# Challenge: Discover - Scroll 2

## Overview
- **Category:** Web Client
- **Points:** 30
- **Difficulty:** Medium
- **Status:** Validated

## Description
Too many rocks to see anything.

## Solution
This challenge involves uncovering a flag that is visually obscured by page elements.
1. Scroll to the bottom of the page to locate the flag.
2. Observe that parts of the flag are hidden by images (rocks) layered over the text.
3. To recover the full flag, use one of the following methods:
   - **Source Code Inspection:** View the page's HTML source code to find the complete flag string.
   - **DOM Manipulation:** Use the "Inspect Element" tool in the browser's developer tools to identify and delete the image elements obscuring the flag.
   - **Visual Adjustment:** Zoom out the page (using `Ctrl + -` or browser settings) until the layout shifts or scales enough to reveal the obscured parts.

## Conclusion
Learned that visual obscuration on a webpage is often just a client-side layer that can be bypassed by inspecting the underlying HTML or manipulating the DOM.
