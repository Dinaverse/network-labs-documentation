# Challenge: Discover - Console 1

## Overview
- **Category:** Web Client
- **Points:** 20
- **Difficulty:** Easy
- **Status:** Validated

## Description
Are you a developer by nature?

## Solution
This challenge introduces the use of the browser's developer console to identify information that is not immediately visible on the rendered page.
1. Open the developer console in your browser (usually via F12 or right-click then "Inspect").
2. Navigate to the **Console** tab.
3. Observe the messages printed to the console. The application automatically logs a message containing the flag upon loading.

## Conclusion
Learned that developers sometimes leave sensitive information or debugging messages in the browser console, which can be easily accessed by anyone using standard web development tools.
